# 1D1T v0.1.0

ONE DAY. ONE THING.

首个终端版本：每天选定一个重点，完成后留下一句话，在贡献日历中回看留下记录的日子。

## 安装

```sh
brew tap vinono/tap
brew install 1d1t
```

## 功能

- 每天一个重点，支持查看、修改、完成与撤销。
- 主动沿用昨天未完成的重点，或补记过去已有的重点。
- 最近 12 周和全年贡献日历、本周及本月统计、历史记录。
- 完全离线，SQLite 数据保存在本机；无需账号，没有完成率或评分。
- 终端欢迎界面、窄终端布局和 `NO_COLOR` 支持。

面向 macOS。Homebrew 自动管理 Python 依赖；源码运行需要 Python 3.9 或更新版本。
原生 macOS App 与同步功能尚未提供。
