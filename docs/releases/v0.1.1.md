# 1D1T v0.1.1

One day. One thing.
Take a day. Feel the love in everything.

v0.1.1 带来银盐冷灰终端视觉升级、更自然的环境变量命名，以及更新后的静态落地页。

## 安装与更新

```sh
brew update
brew upgrade one-day-one-thing
```

首次安装：

```sh
brew tap vinono/tap
brew install 1d1t
```

如果 Homebrew 提示 `untrusted tap`，先信任此 Formula，再重试安装：

```sh
brew trust --formula vinono/tap/one-day-one-thing
brew install 1d1t
```

## 变更与优化

- **银盐冷白终端美学**：终端欢迎界面（`1d1t welcome`）与状态输出统一升级为银盐冷白（Silver Gelatin）风格，去除高饱和荧光绿，呈现沉静纯粹的胶片灰阶质感。
- **全局统一双行标语**：终端、文档与落地页对齐统一为：
  ```text
  One day. One thing.
  Take a day. Feel the love in everything.
  ```
- **环境变量重构**：优化数据目录环境变量为 `ONE_DAY_ONE_THING_DATA_DIR`（支持简写 `ONE_DAY_DATA_DIR`），解决原先 `ONED1T_DATA_DIR` 拼读不顺的问题，同时保持对旧变量的向下兼容。
- **全新纯静态落地页**：采用与终端 `welcome` 一致的主图，并展示最近 12 周的贡献日历示例。
- **交互日历**：`1d1t calendar -i` 可在支持交互的终端中浏览日期。
