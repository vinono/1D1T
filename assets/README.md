## 图标

`1d1t-icon.png`：方形 PNG 图标，使用与终端 Welcome 相同的实心方格字形；
32px favicon 保留 `> ■` 提示符简写。重新生成方式见 [`terminal-welcome.md`](terminal-welcome.md)。
设计为深石墨圆角底、纯净银白终端提示符 `>`、单个纯净银白微光方格光标与 1D1T 字标。
纯白方格同时表示贡献日历中点亮的一天。终端用文字标识 `> ▪ 1D1T` 呼应。
PNG 是品牌素材，当前 CLI 不需要或自动安装 macOS App 图标。
