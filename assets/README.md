# 1D1T 品牌素材

唯一品牌标语：**Take a day. Feel the love in everything.**

当前欢迎界面图为 [`terminal-welcome.png`](terminal-welcome.png)，用于 README 与落地页。
编辑说明与提示词见 [terminal-welcome.md](terminal-welcome.md)。
旧的 `terminal-welcome-concept.*`、`terminal-welcome-love.*` 仅保留为历史设计素材。

## 图标

`1d1t-icon.png`：使用内置 imagegen 生成的方形 PNG 图标。
设计为深石墨色圆角底、浅薄荷色终端提示符、单个亮绿色光标方格和 1D1T 字标。
绿色方格同时表示贡献日历中点亮的一天。终端用文字标识 `> ▪ 1D1T` 呼应。
PNG 是品牌素材，当前 CLI 不需要或自动安装 macOS App 图标。

## 最终生成提示词

Use case: logo-brand. Create one finished square macOS app icon for 1D1T, a terminal-first 'one day, one task' personal focus tool. A refined geek/developer aesthetic: nearly black graphite rounded-square tile, a crisp pale mint terminal prompt chevron > on the left and a single luminous acid-green square cursor on the right. The square cursor also evokes exactly one completed contribution-calendar cell. Under the main mark, small but highly legible custom monospace text exactly '1D1T'. Strong geometric silhouette, generous negative space, pixel-perfect aligned proportions, minimal flat vector-like shapes with only an extremely subtle green halo at cursor, premium restrained design. Straight-on centered isolated icon fills square canvas, dark charcoal background, no perspective, no mockup, no desk, no extra icons, no decorative circuitry, no gradients or excessive bloom, no watermark. Suitable to read as a tiny app icon, 1024x1024.
