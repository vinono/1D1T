YOUR TERMINAL. YOUR DAY.

ONE DAY.
ONE THING.

Take a day. Feel the love in everything.

今天，只做一件重要的事。
在终端选定一个重点，让认真度过的日子慢慢亮起来。

开始今天的第一件事 ↗阅读命令指南 →

macOS · LOCAL FIRST · NO ACCOUNT REQUIRED

SMALL COMMANDS. MEANINGFUL DAYS.

把注意力，留给这一件事。

01 / CHOOSE

选定今日重点

一天一个重点。想清楚今天最重要的事，然后开始。

1d1t add "写完那篇文章"
02 / RECORD

留下一句记录

完成时，为今天留一句话。尚未完成的事可以明天主动沿用。

1d1t done "把想法写下来了"
03 / REFLECT

看见那些日子

用贡献日历回看记录。一天一格，没有完成率或评分。

1d1t calendar

READY WHEN YOU ARE.

打开终端。
从今天开始。

需要 Python 3.9 或更新版本。
离线运行，无第三方 Python 依赖。

TERMINAL / 安装
git clone https://github.com/vinono/1D1T.git
cd 1D1T
python3 scripts/install.py
./bin/1d1t welcome

安装后请保留项目目录。若 1d1t 未找到，请将 ~/.local/bin 加入 PATH。

使用本地 Homebrew Tap 安装 →

[ local ]

你的记录，留在你的电脑里。

无需账号。数据保存在本机 SQLite 中，卸载命令也不会删除记录。当前版本专注终端，未来计划提供原生 macOS App。
