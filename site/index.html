在这个充斥着红点推送与无限待办清单的世界里，1D1T 试图给你的终端留出一片安静的空地。
清晨选定今天唯一的一件事；黄昏留下一句真实的记录。

$ brew tap vinono/tap
$ brew install 1d1t

* 依赖由 Homebrew 自动就绪，离线使用，数据永不出本机。

共计专注记录：48 天 · 没有完成率与评分
01 / CHOOSE

选定今日重点

一天只有一个重点。想清楚今天最重要的事，输入命令，而后放下手机开始。

1d1t add "写完那篇文章"
02 / RECORD

留下一句记录

完成时，为今天留一句话。尚未完成的事可以明天主动沿用，不带自责。

1d1t done "把想法写下来了"
03 / REFLECT

看见那些日子

用贡献日历回看走过的轨迹。一天一格，没有完成率，也没有给生活打分。

1d1t calendar
