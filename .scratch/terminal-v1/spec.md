# 1D1T Terminal V1

Status: complete

## 已确认范围

- 第一版仅终端；未来方向为 macOS App，不做网页。
- 每日本地自然日只有一个重点，可修改；完成后不追加。
- `add` 设置今日重点；重复添加提示用 `edit`，不覆盖。
- `today` 显示今日重点与状态。
- `done [说明]` 标记完成；`done --date 昨天` 或 ISO 日期仅补记已有重点。
- `edit` 修改今日未完成重点；`undo` 撤销今日完成状态。
- `carry` 沿用昨天未完成重点；不自动顺延，不修改昨天。
- `stats --week` / `--month` 展示完成天数和记录，不展示完成率、评分。
- `history` 查看历史事项；`calendar` 显示终端贡献日历。
- 数据在用户目录统一保存，跨工作目录共享，离线可用。

## 实现约定

- 本地日期按运行命令时的系统时区确定，一周从周一开始。
- SQLite 保存数据，版本化 schema 便于未来 App 使用。
- 重复完成不更改原记录；撤销完成会清除对应完成说明。
- 空白文字和终端控制字符拒绝写入；错误有中文提示与非零退出码。
- 统计按照重点所属日期，不按照补记操作发生的时间。
- 默认历史显示最近 30 条，可用 `--limit` 调整。
- 贡献日历默认最近 12 周，支持指定年份；窄终端分段展示。
